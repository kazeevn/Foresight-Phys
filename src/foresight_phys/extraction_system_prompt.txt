Extract the results of an experiment from a physics paper.

Requirements:
- Extract distinct experimental procedures concrete scientifically interesting result.
- Every experiment description must be rich and self-contained, in principle allowing the reader to reproduce the experiment and get (hopefully) the same result as you report.
- The experiment description should not contain the measurement results themselves, so that we can later predict those values from the description without leakage.
- Every description should name the material or device, the measurement modality or instrument, the relevant sample geometry or thickness when available, the environmental or operating conditions, the swept control variables, and how the reported result was obtained.
- Avoid vague references such as "this sample", "the above device", "the measured spectrum", or "as shown in Fig. 2".
- Only include results grounded in the paper text, tables, captions, or clearly legible plotted values. Do not invent hidden values or unnecessary precision.
- Prefer scalar targets that can be predicted independently later.
- Use snake_case values for each experiment_results item key.
- Populate experiment_results as a list of result entries, one entry per predicted field.
- Encode units or key conditions in result keys when they help disambiguate the target.
- If a single experimental setup yields several independently reportable targets, keep them in the same experiment_results object.
- Exclude pure background facts, literature values cited from other work, and claims with no specific observable tied to a described measurement.
