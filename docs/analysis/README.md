# Foresight-Phys analysis

Post-hoc analysis of benchmark runs: pulls per-field predictions out of each
run's HTML report, joins them against ground truth, classifies fields by
cross-model difficulty, and writes summary statistics + plots.

This is a *separate* tool from the benchmark CLI itself — it consumes the
artifacts the benchmark writes into `docs/<run-name>/`.

## Contents of this directory

| Path | What it is | Regenerated by |
|---|---|---|
| `analysis.md` | The human-readable writeup of conclusions. | hand-written |
| `summary.json` | Headline numbers (per-model means, difficulty distribution, leakage impact, numeric thresholds, categorical baselines). | `analyze` step |
| `plots/*.pdf` | One figure per file, suitable for inclusion in a paper. | `plots` step |
| `README.md` | This file. | hand-written |

Intermediate parquet artifacts are written under `.cache/analysis/` (not
committed):

| Path | Contents |
|---|---|
| `.cache/analysis/predictions.parquet` | One row per `(run, model, paper, experiment, key)` with the raw ground-truth string, predicted string, and the HTML report's status class. |
| `.cache/analysis/scored.parquet` | Same rows enriched with `type` from the ground-truth JSON, parsed numerics, sMAPE, normalized sMAPE, per-field `score` (matching `compute_experiment_metrics`), and `leak` / `likely_unit_off` flags. |
| `.cache/analysis/per_field.parquet` | One row per `(paper, experiment, key)` with each model's `correct`/`score`/`smape` as wide columns, plus `n_correct` and a `difficulty` label. |

Delete the cache directory to force a clean rebuild; the writeup, summary,
and plots will all be regenerated from scratch when the pipeline is rerun.

## Regenerating everything

```bash
uv run --env-file .env foresight-phys-analysis all
```

That runs four steps in order:

1. **`parse`** — walks every `docs/<run-name>/` directory that contains a
   `benchmark_human_readable_report.html` and a `benchmark_results.json`,
   parses the per-field table out of the HTML, and writes
   `.cache/analysis/predictions.parquet`. New runs are picked up
   automatically.
2. **`build`** — joins those rows against the ground-truth JSON files in
   `JSONs/filtered/`, parses numerics, computes sMAPE / score / leakage,
   and writes `.cache/analysis/scored.parquet`.
3. **`analyze`** — pivots to per-field-across-models, classifies each field
   as `trivial | easy | discriminative | hard | intractable`, computes
   per-model summaries, numeric accuracy thresholds, the constant-predictor
   numeric baseline, the categorical-random baseline, the leakage impact,
   and writes `summary.json` + `.cache/analysis/per_field.parquet`.
4. **`plots`** — renders 9 figures from the parquets and writes one PDF per
   figure under `plots/`.

You can run any step on its own (each step assumes its predecessors have run):

```bash
uv run foresight-phys-analysis parse
uv run foresight-phys-analysis build
uv run foresight-phys-analysis analyze
uv run foresight-phys-analysis plots
```

By default everything is anchored at the current working directory; pass
`--project-root /path/to/repo` to run from elsewhere.

## Module layout

The code lives in `src/foresight_phys/analysis/` so it ships with the
package and is importable from notebooks:

```python
from foresight_phys.analysis import (
    parse_all_runs, build_scored_dataset, write_summary, write_all_plots,
)
from foresight_phys.analysis.paths import default_paths

paths = default_paths()
parse_all_runs(paths)
build_scored_dataset(paths)
write_summary(paths)
write_all_plots(paths)
```

| Module | Responsibility |
|---|---|
| `paths.py` | `AnalysisPaths` dataclass with all output locations; `default_paths()` resolves them relative to `cwd`. |
| `parse_runs.py` | HTML report parsing — auto-discovers run directories under `docs/`. |
| `build_dataset.py` | Numeric coercion, scoring, leakage / unit-mismatch flags. The per-field `score` here matches `metrics.compute_experiment_metrics`. |
| `analyze.py` | Cross-model pivot, difficulty classification, numeric thresholds, baseline computation, `summary.json` writer. |
| `plots.py` | One function per figure; `write_all_plots` runs them all. |
| `cli.py` | `argparse` entry point exposed as `foresight-phys-analysis`. |

## Figure index

| File | What it shows |
|---|---|
| `plots/aggregate_by_model.pdf` | 4 headline metrics (overall, numeric sMAPE, bool/cat, formula) per model. |
| `plots/difficulty_distribution.pdf` | How many fields are trivial / easy / discriminative / hard / intractable, overall and by result type. |
| `plots/numeric_thresholds.pdf` | Fraction of numeric predictions within ±30%, ×2, and 1 decade, with a constant-predictor baseline. |
| `plots/numeric_log_ratio_cdf.pdf` | CDF of \|log10(pred/gt)\| per model + constant baseline. |
| `plots/numeric_scatter.pdf` | log–log scatter of \|pred\| vs \|gt\|, one panel per model. |
| `plots/paper_dominance.pdf` | How the largest-by-field paper warps the aggregate. |
| `plots/model_agreement.pdf` | Jaccard agreement matrix on the set of fields each model got right. |
| `plots/per_paper.pdf` | Per-paper mean score, sorted by cross-model mean. |
| `plots/leakage_effect.pdf` | Mean score on fields whose literal numeric answer appears in the description, vs fields where it doesn't. |
